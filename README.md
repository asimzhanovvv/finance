# Финансы

Личный учёт трат на iPhone: шорткат «Финансы» + страница статистики на GitHub Pages.

**Сайт:** https://asimzhanovvv.github.io/finance/

## Как это устроено

- После оплаты через Apple Pay (или вручную) шорткат спрашивает категорию и сумму и дописывает строку в `iCloud Drive/Shortcuts/finance.txt`.
- «Статистика» сжимает файл (gzip), кладёт его в адрес страницы после `#` и открывает сайт. Часть адреса после `#` браузер не отправляет на сервер, поэтому GitHub траты не видит: в репозитории только код страницы.
- Правки на сайте (категории, удаление, сжатие) копируются в буфер обмена, сайт запускает шорткат с `APPLY`, шорткат перезаписывает файл и делает `finance-backup.txt`.
- AI-советы: сайт отправляет короткую сводку в шорткат, тот спрашивает модель Apple Intelligence на устройстве и снова открывает статистику.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | страница статистики (графики, дни, категории, советы) |
| `finance.cherri` | исходник шортката на [Cherri](https://cherrilang.org), подписывается в [Playground](https://playground.cherrilang.org) |

## Формат finance.txt

```
FIN1
s|cur|₸                     настройки
s|budget|150000
c|a|food|Еда|1             категория: id|иконка|название|цвет 1..12
2610190915|3500|a|Magnum    трата: yyMMddHHmm|сумма|категория|заметка
x|2610190915|3500           отмена траты
d|250301|a|12400|4          сжатый день: дата|категория|сумма|кол-во
a|2610191300|совет ¶ совет  последний AI-совет
```

5 трат в день дают около 55 КБ в год (около 15 КБ в адресе после gzip). Когда данных станет много, в настройках сайта есть «Сжать старые данные».
